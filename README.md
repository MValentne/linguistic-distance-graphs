# Linguistic Distance Graphs

Espacio de investigación colaborativo. El objetivo es explorar la representación de distancias entre idiomas como un grafo ponderado, y aplicar algoritmos de análisis de grafos para descubrir estructuras y patrones en esa red.

## Enfoque

La investigación se centra en la **parte computacional**: qué algoritmos de grafos pueden aplicarse, qué revelan sobre la estructura de las distancias lingüísticas, y cómo comparar distintas aproximaciones. Los datos lingüísticos (listas de Swadesh, base ASJP) son el dominio de entrada, no el objeto de estudio principal.
